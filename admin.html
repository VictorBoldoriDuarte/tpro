          1. Abra a loja em outra aba do navegador.

            Dados e backup

            Exportar catálogo

            Baixe um arquivo com todos os produtos, categorias e planos. Serve como backup e para levar o catálogo para outro computador.

            Importar catálogo

            Substitui o catálogo atual pelo conteúdo de um arquivo exportado anteriormente.

            Restaurar catálogo padrão

            Volta para os 16 produtos de demonstração que vieram com o projeto. Tudo o que foi cadastrado neste navegador é descartado.

            Onde os dados ficam salvos

            Nesta demonstração, o catálogo é gravado no armazenamento local deste navegador — sem servidor e sem envio de dados. Ao conectar o backend, o painel passa a gravar direto no banco, e o mesmo catálogo aparece para todos os membros.
